# Clone do Spotify

Este é um projeto de clone do Spotify, desenvolvido para fins educacionais. O objetivo é criar uma interface semelhante à do Spotify, utilizando tecnologias web modernas.

## Tecnologias Utilizadas

- HTML 5
- CSS 3
- JavaScript (ES6+)
- Tailwind CSS (versão 4.x)
- Node.js (versão 24.x)

## Finalidade

Projeto utilizado como base de ensino, e treinamento, dos cursos de **Informática**,
principalmente de nível técnico - **IFSP**.

## Instalação

1. Clone este repositório:

```bash
git clone https://github.com/dennyazevedofh/CloneSpotify.git
```

2. Navegue até o diretório do projeto:

```bash
cd CloneSpotify
```

3. Instale as dependências:

```bash
npm install
```
